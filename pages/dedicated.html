Выделенный сервер (Dedicated Server)

Суть и принцип работы

Выделенный сервер (dedicated server или «дедик») — это физический сервер в дата-центре провайдера, который арендуется целиком под ваш проект. Не виртуальная машина, где ресурсы делятся с соседями, а целая машина: процессор, память, диски — всё работает только на вас. Никакой борьбы за CPU с десятком других клиентов, никаких просадок производительности из-за того, что сосед по гипервизору запустил обучение нейросети. Ресурсы предсказуемы, производительность стабильна.

Клиенту предоставляется отдельный физический сервер с полными администраторскими правами. Вариант подходит владельцу среднего бизнеса.

Преимущества

  • Гарантированная производительность, предсказуемость, максимальная автономность.
  • Вы получаете максимальную мощность, так как ни с кем не делите комплектующие сервера и не теряете производительность на установке гипервизоров.
  • Минимум ограничений.

Недостатки

  • Выделенный сервер, как правило, стоит существенно дороже.
  • Есть вероятность, что в моменты снижения нагрузки полная мощность сервера окажется невостребованной.
  • Проблемы с наращиванием мощностей (невозможно обойтись без апгрейда комплектующих).
  • Требуется наличие в штате технического специалиста.

Когда выбирать

Выделенные физические серверы выбирают те, кому необходимо работать с большими объемами данных, а мощностей нескольких VDS/VPS-серверов для этого не хватает. Подходит для высоконагруженных систем и приложений, БД с высокой нагрузкой, критичных веб-приложений, низколатентных сервисов.
